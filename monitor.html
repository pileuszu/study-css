3D 모니터 시뮬레이터 원리 (Technical Mechanics Explanations)

이 시뮬레이터는 웹 그래픽스 라이브러리(Three.js 등)의 도움 없이, 순수하게 브라우저 자체의 CSS 3D Transforms (preserve-3d) 성능과 Web Audio API 주파수 합성 능력을 응용해 설계되었습니다.

  • 1. 3D 구조적 조립 (3D Cuboid Assembly):
    모니터 패널은 중앙 3D 레이어(`monitor-panel-3d`)를 축으로 하여 앞면(Screen), 뒷면(Casing Cover), 그리고 두께를 잇는 4개의 측면 판넬이 각각 `translate` 및 `rotate` 연산으로 정교하게 결합된 3차원 입체 육면체 구조입니다.
  • 2. 물리적 다이나믹 피벗 조작 (Interactive Pivot Dynamics):
    모니터 스탠드의 높이조절(Height Lift), 틸팅(Tilt - Pitch), 스위블(Swivel - Yaw) 동작은 CSS 변수(--monitor-height 등) 변경 시 실시간으로 Z축 변위 및 3D 회전 행렬 연산에 대입되어 키보드 조작 패널을 조절하듯 물리적인 모니터 외형이 왜곡 없이 실시간 구동됩니다.
  • 3. 몰입형 앰비라이트 효과 (Ambilight Sync & Backglow):
    모니터 뒤에 맺히는 백라이트 글래스 효과는 스크린의 현재 화면 모드(코드, 터미널, 그래픽)의 배경 그라데이션 및 색상 채도값과 동기화되어, 뒤쪽의 3차원 입체 가상 벽면에 부드러운 LED 간접 조명(Ambilight) 형태로 자연스럽게 연출됩니다.
  • 4. 양방향 시뮬레이션 및 터미널 쉘 (Bilateral Shell Emulation):
    테스트 입력 박스에 명령어를 입력(예: `help`, `status`, `matrix`, `ping`)하고 엔터를 입력하면, 모니터 스크린 속 터미널(Terminal) 모듈 내부 스크립트 엔진이 인풋을 가로채 쉘 출력을 시뮬레이션하는 완벽한 양방향 인터랙션을 지원합니다.
